Student Management System

Project Overview

The Student Management System is a SQL-based database project developed using MySQL. It helps manage student information and academic records.

Technologies Used

- MySQL
- MySQL Workbench
- SQL

Database Tables

1. Departments
2. Students
3. Courses
4. Marks
5. Attendance
6. Fees

SQL Concepts Used

- CREATE DATABASE and CREATE TABLE
- INSERT, SELECT, UPDATE and DELETE
- WHERE, ORDER BY and LIMIT
- DISTINCT
- Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)
- JOINS
- Primary Key and Foreign Key

Project Features

- Manage student details
- Store department and course information
- Maintain student marks
- Track attendance
- Manage fee payment records

Project File

"sms_project.sql" contains the SQL queries used in this project.
